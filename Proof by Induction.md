# Proof by Induction
We want to establish an if/else rule.
Assume the statement is true for an arbitrary value $k=n$. Is the statement also true for $k=n+1$?
Then, we prove the statement is true for the base case, $k=1$
Next, our rule kicks in. Since it's true for $k=1$, then it's true for $k=2$. And since it's true for $k=2$, then it must be true for $k=3$. And so on.
Thus we prove the statement is true for any k
